# 🧮 Python as a Calculator Using REPL

## 📌 About

This project demonstrates how Python can be used as a simple calculator using the **Python REPL (Read-Evaluate-Print Loop)**.

Python's interactive mode allows us to write expressions and immediately see their results without creating a separate Python file.

---

## 🚀 What I Learned

Using Python REPL, I practiced basic mathematical operations such as:

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Modulus (`%`)
* Exponentiation (`**`)

---

## 💻 Examples

### Addition

```python
>>> 2 + 3
5
```

### Subtraction

```python
>>> 10 - 4
6
```

### Multiplication

```python
>>> 5 * 6
30
```

### Division

```python
>>> 10 / 2
5.0
```

### Modulus

```python
>>> 10 % 3
1
```

### Exponentiation

```python
>>> 2 ** 3
8
```

---

## 📚 Using Variables in REPL

Python REPL can also be used with variables:

```python
>>> a = 10
>>> b = 5

>>> a + b
15

>>> a * b
50
```

---

## 🧠 What is REPL?

**REPL** stands for:

* **Read** – Python reads the command.
* **Evaluate** – Python evaluates the command.
* **Print** – Python displays the result.
* **Loop** – Python waits for the next command.

---

## ▶️ How to Run Python REPL

Open your terminal or command prompt and type:

```bash
python
```

You will see:

```text
>>>
```

Now you can directly perform calculations:

```python
>>> 5 + 5
10
```

To exit the REPL:

```python
exit()
```

---

## 🎯 Key Takeaway

Python is not only used for writing complete programs. Its interactive **REPL mode** can also be used as a quick calculator to perform calculations and test Python expressions instantly.
